For this project, the selected prediction task is \*\*Appointment No-Show Prediction\*\*, where machine learning is used to predict whether a patient is likely to attend or miss a scheduled hospital appointment.

\# SmartCare AI – Appointment No-Show Prediction



SmartCare AI is a machine-learning based appointment no-show prediction system developed for the CCS3440 Artificial Intelligence coursework.



\## Prediction Task



The system predicts whether a patient is likely to miss a scheduled hospital appointment.



\- Target Variable: `no\_show`

\- Problem Type: Binary Classification

\- Class 0: Attended / Other

\- Class 1: No-Show



\## Machine Learning Models



The following models were developed and compared:



\- Logistic Regression

\- Decision Tree

\- Random Forest



Logistic Regression was selected as the final model based on test-set performance.
